OSINT BR

Investigação com dado público

31 ferramentas de OSINT, uma linha de comando só.

OSINT BR reúne coletores de código aberto e APIs gratuitas para investigar pessoa, empresa, domínio, e-mail, arquivo, voo, navio e coordenada — cada achado registrado num banco só, com relatório e grafo de conexões no final. Ética por padrão: só dado público, com limite de requisições em cada coletor.

O problema

Cada ferramenta OSINT boa vive isolada, com seu próprio formato de saída.

Sherlock acha usuário, theHarvester acha e-mail, ExifTool lê metadado de foto — cada uma ótima na sua tarefa, cada uma com saída, banco e comando diferentes. Cruzar o que elas encontram exige copiar e colar entre telas. OSINT BR junta essas ferramentas — e chamadas de API complementares — num orquestrador só: um alvo, um banco, um relatório.

Como funciona

Um alvo, 31 coletores possíveis, um relatório no fim.

31 coletores, 10 categorias

De sherlock e maigret (usuário) a brasilapi_cnpj (empresa) e exiftool (GPS de foto) — cada coletor documenta a própria fonte e o que deliberadamente não coleta.

Chave validada na hora

Antes de salvar uma chave de API no .env, o comando testa contra o endpoint de status da própria API — nunca grava chave inválida sem avisar.

Relatório e grafo

Cada alvo investigado vira um relatório em Markdown, um grafo de conexões em HTML e um export estático (JSON + GeoJSON) pronto pra reaproveitar.

Imagens por similaridade

Indexa fotos por dHash para achar duplicatas e buscar por similaridade — útil pra checar se uma imagem já circulou em outro lugar.

Bloqueio por decisão de projeto

Ferramentas que violam termos de uso — GHunt, Truecaller, Osintgram, Toutatis, raspagem de Flightradar24/MarineTraffic — ficam de fora, não escondidas atrás de uma flag.

Rate limiting obrigatório

Todo coletor roda com limite de requisições (--sleep, --limit) — investigar não pode virar sobrecarga pra fonte.

Ética

Só dado público. Sempre.

Nenhum coletor acessa informação privada ou vazada além do que a própria fonte já publica abertamente. Relatórios são para uso legítimo e documentado, respeitando a LGPD.

Estado atual: em desenvolvimento, uso via linha de comando. Framework CLI completo (31 coletores) lançado em agosto de 2026; a vitrine web (Cloudflare Pages) ainda não tem deploy público.
