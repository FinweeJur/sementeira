Hermes Desktop

Um agente de IA, na sua máquina

Converse com um agente de IA sem entregar a conversa a ninguém.

Hermes Desktop é o app desktop (Electron) para conversar com o Hermes Agent — com modelos locais via Ollama ou provedores em nuvem (DeepSeek, Maritaca), memória de sessão entre conversas e interface em português e inglês. As chaves de API ficam criptografadas na própria máquina.

O problema

Um chat de IA decente ou é todo em nuvem, ou não guarda contexto nenhum.

A maioria dos assistentes de IA desktop força escolher entre depender de nuvem alheia ou perder a memória da conversa a cada sessão. Hermes Desktop deixa a escolha do provedor com quem usa — local com Ollama, sem nada saindo da máquina, ou nuvem quando faz sentido — e guarda o histórico de conversa de qualquer jeito.

Como funciona

Um app, dois jeitos de rodar o modelo.

Local ou nuvem

Ollama local por padrão, ou DeepSeek/Maritaca na nuvem — trocar de provedor é uma configuração, não uma reinstalação.

Chaves criptografadas

As chaves de API ficam em config.json cifradas em AES-256-GCM; o segredo de criptografia é único por instalação, então uma cópia do repositório não descriptografa as chaves de outra máquina.

Memória de sessão

O histórico de conversas fica salvo localmente, fora do controle de versão — retomar de onde parou não depende de nenhum servidor.

Português e inglês

Interface nos dois idiomas, pensada para uso no dia a dia sem fricção de tradução.

Testado de ponta a ponta

Testes unitários em Jest e testes end-to-end em Playwright cobrem o fluxo principal antes de cada mudança.

Estado atual

Funcional em uso local.

config.json, o segredo de criptografia (.hermes-secret) e o histórico (history.json) ficam fora do git — cada instalação guarda as próprias chaves e conversas, sem backup automático.

Sem instalador público ainda — uso interno, via npm install && npm start (start-hermes.bat no Windows).
